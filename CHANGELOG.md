# Changelog

All notable changes to HyStudio are listed here. Versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-14

First public release.

### Added

- 3D view with mouse selection of parts and material groups.
- Realistic materials: gloss, satin or matte paint, chrome, metal, plastic, rubber, glass, mask.
- Stickers laid over any material, with size, position and rotation, spanning a whole group if needed.
- Image material for flat parts such as licence plates.
- glTF 2.0 import (`.gltf`, `.glb`) with textures, normal maps, emission and transparency.
- OBJ import with automatic unit detection and optional use of the `.mtl` file.
- Detection of models that are not split into parts, with the matching feature set.
- One-click Blender Cycles preview at the head unit's exact format (800 × 424).
- Full rotation generation (180, 360 or 720 views) with live compression and estimated finish time.
- SD card installation with integrity check, MD5-verified copy and automatic eject.
- Unlimited undo and redo.
- Interface in 9 languages with automatic detection and a Language menu.
- Validated Hyundai i20 profile.
- `.hysp` project format; `.hyproj` and `.carproj` projects still open.
